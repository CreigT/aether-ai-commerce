# AetherCommerce — Autonomous AI Commerce Platform

**Day 1 Module: Simple AI Commerce Landing Page & Storefront**

Production-ready, static HTML site. Deploy to Vercel by importing this GitHub repo. Add your Stripe payment links and any environment variables. The agents handle the rest conceptually.

## Quick Deploy

1. Fork or use this repo.
2. Import into Vercel (Vercel detects static site automatically).
3. Replace Stripe placeholder links in `index.html` with your real payment links.
4. Push. Done.

## Module Documentation

See the full 30-point specification in the daily deliverable response.

## Structure

- `index.html` — Landing, store, pricing, FAQ
- `styles.css` — Dark theme, responsive
- `script.js` — Cart & interactions

## Variables to Customize

- Stripe payment links (Pro plan and checkout)
- Brand name / logo text
- Product details
- Contact email

This is the foundation. Future daily modules will add real backend agents, APIs, and deeper automation while keeping the public face simple and understandable.
